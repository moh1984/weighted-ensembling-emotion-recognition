## What this package is

Everything needed to verify the numbers reported in the article: the protocol
frozen before any model was trained, the feasibility report and the amendment
bound to it, split index files, per-sample predictions and metadata for every
run, training and analysis configurations, the data-construction, training,
verification and analysis code, the analysis outputs, hash manifests, and Git
provenance records documenting the pre-training freeze commit.

## What is deliberately not here

**No corpus text and no author identifiers.** The article states that corpus
text is not redistributed, and this package honours that. Files withheld for
this reason are listed with their paths and sizes in
`EXCLUDED_FROM_PUBLIC_RELEASE.txt`.

This does not limit verification:

- **Reported results** are recomputable from the per-sample predictions and the
  recorded validation scores included here, using the included analysis code and
  its frozen specification.
- **The corpus and the splits** are rebuilt exactly by obtaining the original
  sources — GoEmotions, and the pinned `cardiffnlp/super_tweeteval` TweetEmotion
  redistribution at the revision recorded in the manifests — and running the
  included build script. Its output is checked against the published content
  hashes, and the build fails closed on any mismatch.

## Verifying this package


## Part C in this public release

`partC/frozen_v2/` retains the manifests, identifier lists, configurations and
freeze receipts, but **the twelve `.parquet` files carrying corpus text are
intentionally omitted**. `partC/frozen_v2/FREEZE.sha256` therefore cannot be
verified in full from this package alone: its hashes are retained as provenance
evidence, and become checkable once the data files are rebuilt from the original
sources with the included build script.

## Recomputing the reported results

Part-A analysis, from the extracted root:

```bash
python repository/current_working_project/partA_analysis/analyze_partA.py \
  --run --project-root repository \
  --checkpoint partA/predictions_checkpoint45 \
  --config repository/current_working_project/partA_analysis/partA_analysis_config.json \
  --out-dir partA/recomputed_results \
  --confirm RUN_FROZEN_PARTA_ANALYSIS
```

Deterministic under its recorded seed. The 10,000-permutation and
10,000-bootstrap computation takes time; no model retraining is required.

## Rebuilding the corpus and splits

The author-block assignment files (`splits/seed*/jury_blocks.json`) are withheld
because they list source author identifiers. They are regenerated by the included
construction pipeline once the corpus is rebuilt, and the reported results do not
depend on them: the per-sample predictions and the effective-training-identifier
hashes recorded with every run already determine what each juror saw.


Obtain GoEmotions and the pinned `cardiffnlp/super_tweeteval` TweetEmotion
redistribution at the revision recorded in the manifests, then run the included
build script. Its output is checked against the published content hashes and the
build fails closed on any mismatch.
